# 🖐️ Hand Gesture Recognition AI

### AI-Based Hand Gesture Detection Web App
*Built with HTML + CSS + JavaScript — Real-Time Gesture Detection in Browser*

---

## 🔍 What is this project?

**Hand Gesture Recognition AI** is a web-based application that detects
and recognizes hand gestures in real-time directly in your browser —
no installation needed!

Just open the website, allow camera access, and the AI will start
recognizing your hand gestures instantly.

Gestures it can detect:

- ✋ Open Hand
- ✊ Closed Fist
- 👆 Pointing Up
- 👍 Thumbs Up
- ✌️ Peace Sign
- 🤟 Rock On

---

## ✨ Main Features

- **Real-Time Detection** : Works live through your browser webcam
- **No Installation** : Runs directly in the browser — nothing to install
- **AI Powered** : Uses TensorFlow.js / MediaPipe for gesture detection
- **Responsive Design** : Works on both desktop and mobile browsers

---

## 🛠️ Tech Stack

**Languages:** HTML | CSS | JavaScript

**AI Libraries:** TensorFlow.js | MediaPipe Hands

**Tools:** Google Antigravity IDE | Git/GitHub

---

## 🚀 How to Use

1. Open the live website link below
2. Allow camera permission when asked
3. Show your hand in front of the camera
4. The AI will detect and display your gesture in real-time ✅
